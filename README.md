```
.
├── main.tex                    # 主文件：导言区、定理环境、章节样式
├── main.pdf                    # 编译产物（未纳入版本控制）
├── chapters/
│   ├── ch01-determinant.tex    # 第一章拼装入口
│   ├── ch01/part0..part5.tex   # 第一章正文分片（按原稿页码切分）
│   ├── ch02-matrix.tex         # 第二章拼装入口
│   └── ch02/part0..part2.tex   # 第二章正文分片
└── .gitignore                  # 排除编译中间文件
```

正文按原稿页码切成 `partN.tex`，由各章的入口文件 `\IfFileExists` 依次 `\input`。
这样即便某一章尚未转录完，仓库也始终处于可编译状态。

## 编译

需要 TeX Live（含 `ctex`、`amsmath`、`mathtools`、`tikz`）与中文字体。
本项目在 TeX Live 2026 + Windows 字体（SimSun / SimHei）下测试通过：

```bash
xelatex main.tex
xelatex main.tex   # 第二遍生成目录与交叉引用
```

或：

```bash
latexmk -xelatex main.tex
```

> 若使用其他平台，把 `main.tex` 中的 `ctexbook` 字体配置改为本机可用的中文字体即可。

## 排版约定

- **层级**：`第一章 行列式` → `1.1 线性方程组的求解` → `1.1.1 二元线性方程组与二阶行列式`。
- **定理环境**：`definition` / `proposition` / `theorem` / `lemma` / `corollary` / `example` / `remark`，
  均按章编号（如「定义 1.3」「命题 2.4」），证明统一用 `proof` 环境、以 □ 收尾。
- **公式编号**：需要在正文中被引用的公式加 `\tag`（如 $(\star)$、$(\ast)$）。
- **交叉引用**：一律用 `\label` / `\ref`，不在正文硬写编号。
- **插图**：原稿手绘的几何示意图一律用 TikZ 重画，不做截图。
- **超宽公式**：用 `\resizebox{\linewidth}{!}{$\displaystyle ...$}` 压到页宽内。

## 关于原稿勘误

原稿是手写笔记，存在少量笔误（下标写错、符号写反、个别算术结果对不上）。
处理原则是：

1. **按数学正确形式排版**，保证读者拿到的是可用的内容；
2. 在原稿的写法确有意义或结果存疑时，**照录原状**并加注释；
3. 每一处改动都在该行末尾留下

   ```latex
   % 原稿作 <原稿写法>
   ```

   形式的注释，便于对照扫描件复核。

同样地，个别字迹无法辨认处会标 `% TODO`，便于后续补全。
